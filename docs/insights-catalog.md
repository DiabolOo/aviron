Relecture avant de brancher l'UI. Code : `src/core/training/insights/` (seuils : `thresholds.ts`, textes : `copy.fr.ts`).

**Conventions** : `id = ruleId:periodKey` (stable pour pouces et rejets) · `date = today` · `message` = texte débutant si `level === 'beginner'`, sinon texte sportif · `confidence = min(1, séances utilisées / (2 × minimum requis))` · toute règle renvoie `null` si les données sont insuffisantes · `evidence` toujours avec `numeric`.
`rankInsights(list, { max: 3, seenIds? })` : gravité (warning > notice > info), puis nouveauté (id non vu, date récente), puis ordre des règles ; une seule carte par `ruleId`.

## Points à valider à la relecture

- **« Course confirmée »** : le contexte n'a pas de flag de confirmation ; on retient les candidates de confiance `high` (distance compatible ou confirmée manuellement). Les candidates `medium` (nom évocateur) sont ignorées par `race_pacing` et le bilan `race_prep`.
- **Sources** : `data_quality_no_hr`, `race_pacing`, `race_prep` → `coach` ; `intensity_too_high`, `volume_ramp`, `consistency`, `aerobic_trend` → `trend` ; `gap_resume` → `recovery`.
- **Gravités** : `warning` réservé à `intensity_too_high` (≥ 60 %) et `volume_ramp` (≥ +50 %).
- **Constantes de conseil** (dans `thresholds.ts`) : FC « facile » = 75 % de la FC max, reprise de 20 min, volume suivant = moyenne + 10 %, sortie longue +1 km/semaine.
- Les fenêtres sont glissantes (7 jours), pas calées sur les semaines ISO ; la clé `periodKey` des tendances est la semaine ISO de `today`.
- Les pourcentages de comparaison sont arrondis à 0,1 avant le seuil (évite 30,000…04 % > 30 %).
